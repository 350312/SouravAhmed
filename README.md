# Sourav Ahmed — Portfolio

A personal portfolio web application for Sourav Ahmed (Mentor, Developer, and aspiring AI Engineer), built with React, TypeScript, and Vite.

## Features

- **Hero Section**: Interactive SVG neural node graph with quadratic curved flow paths and animated pulse dots, animated gradient headings, and profile badge.
- **About Section**: Professional background, education (St. Joseph Higher Secondary School, Bangladesh University of Professionals), and technical focus in AI engineering & automation.
- **Skills Matrix**: Categorized tech stack breakdown (Languages, Frameworks & Libraries, AI & Automation, Tools) with animated skill bars.
- **Projects Showcase**: Interactive project gallery with tags, descriptions, tech stacks, and live links.
- **Admin Management**: Unlockable project editor (password: `sourav123`) to add, update, and remove projects with persistent storage.
- **Contact**: Direct communication channels (Email, Phone, LinkedIn, GitHub).
- **Responsive & Dark-Themed**: Sleek custom dark violet palette with glassmorphism navbar and mobile navigation.

## Development

```bash
# Install dependencies
npm install

# Start development server on port 3000
npm run dev

# Build production bundle
npm run build
```
